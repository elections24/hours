Election data isolation

An agent is scoped to the selected election and geographical assignment. Example: Presidential + Zamfara State must not expose Gubernatorial or other-state records.

This dashboard stores the election type, role, and assignment on each agent profile. Your Firestore Security Rules must also enforce the same scope on report reads and writes; hiding other elections in the interface alone is not security.

Register Agent

Create an agent account and bind it to one election and one geographical scope.

1. Select Election Type
Role selection is step 2. Senatorial election includes Senatorial Zone Agent; House election includes Federal Constituency Agent.
2. Agent Account Details
Minimum 6 characters. Give the agent the password securely and ask them to change it after first login.
3. Assign Geographical Coverage

Choose State first. Each next dropdown is filtered by the preceding selection. For State Collation Agent, State is the only required geographical level.

Senatorial Election: State → Senatorial Zone → Local Government → Ward → Polling Unit. The Senatorial Zone Agent receives access to all LGAs assigned to that zone.
House of Representatives: State → Federal Constituency → Local Government → Ward → Polling Unit.

Account creation note

Firebase & Data Guide

Project connection and required data model.

Connected Firebase project

This file uses the Firebase configuration from your THE EYES V3 agent registration and Super Admin login files.

Project ID: election-8e790
Firestore: users/{uid} for account role verification; electionAgents/{uid} for agent assignment profiles; geography master collections listed below.

Firestore collection structure

  • users/{uid} — account profile, role, active/status
  • electionAgents/{uid} — electionType, agentRole, geography, assigned scope, account status
  • geographyStates/{stateCode}
  • geographySenatorialZones/{zoneCode} — stateCode parent
  • geographyFederalConstituencies/{constituencyCode} — stateCode parent
  • geographyLGAs/{lgaCode} — stateCode plus optional zoneCode/constituencyCode
  • geographyWards/{wardCode} — lgaCode parent
  • geographyPollingUnits/{pollingUnitCode} — wardCode parent

Reports should store electionType and location identifiers, and Firestore Security Rules must validate those fields against the authenticated user's assignment.

Important production security

Firebase web configuration is public by design; Firestore Security Rules and a trusted server-side function are the security boundary. Do not rely on hiding pages or filtering dropdowns to enforce access. The account creation flow is currently client-side and should be migrated to a protected Cloud Function/Admin SDK before broad production deployment.
